# ESP32 Traffic Light

A multi-phase, easy-to-configure traffic light controller built for the ESP32 using Arduino C++. 
It's starting small but more changes will come as prof decides to add more milestones

## Pin Configuration
1. **Red LED:** GPIO 15
2. **Yellow LED:** GPIO 16
3. **Green LED:** GPIO 17

## Timing Sequence
1. **Red:** 5 seconds
2. **Yellow:** 10 seconds
3. **Green:** 30 seconds
